# Memory layers

Use three distinctions even when a backend gives them different names:

- **Runtime/context**: short-lived facts needed for the current run.
- **Searchable documents**: source material that can be retrieved and cited.
- **Curated memory**: supervised, durable facts with provenance and a clear scope.

Moving information upward is a review operation. Record the source path, the claim, why it is reusable, and what would invalidate it.
